# Intelligent Cognitive Alarm Platform

An intelligent alarm platform designed to improve wake-up consistency through user profiling, wake-up verification, cognitive challenges, adaptive difficulty, habit scoring, analytics, and reporting.

---

## 📌 Project Overview

The **Intelligent Cognitive Alarm Platform** is a backend-driven system that goes beyond a traditional alarm by evaluating the user's wake-up behavior and challenge performance.

The platform records user activity such as:

- Wake-up verification
- Cognitive challenge performance
- Attempts
- Time taken
- Success/failure
- Adaptive difficulty
- Habit score
- Overall performance

The collected information is processed by the backend to generate analytics and reports that can be consumed by the frontend application.

---

## 🎯 Objectives

The main objectives of the project are:

- Provide user profile management.
- Verify whether the user has successfully woken up.
- Evaluate cognitive challenges.
- Adapt challenge difficulty based on user performance.
- Calculate wake-up and habit-related scores.
- Provide analytics about user performance.
- Generate structured reports for visualization.
- Validate backend APIs through automated testing.
- Provide APIs that can be integrated with the frontend application.

---

## 🚀 Key Features

### 1. User Profile Management

The platform maintains user profile information required by the cognitive alarm system.

### 2. Wake-Up Verification

The system verifies whether the user successfully completes the wake-up process.

### 3. Challenge Evaluation

Cognitive challenges are evaluated based on:

- User answer
- Correct answer
- Score
- Attempts
- Time taken
- Pass/Fail status

### 4. Adaptive Difficulty

The platform determines the user's current challenge level and recommends the next difficulty level based on performance.

### 5. Habit Scoring

The system calculates different behavioral scores, including:

- Wake-up score
- Challenge score
- Snooze score
- Sleep score
- Overall score
- Grade

### 6. Analytics

The Analytics API aggregates information from the existing modules and provides a consolidated view of user performance.

🔒 Security

Database credentials are managed using environment variables instead of being hardcoded into the application.

The .env file is excluded from version control using .gitignore.

Example:

load_dotenv()


DATABASE_URL = os.getenv("DATABASE_URL")

This prevents sensitive database credentials from being exposed in the source repository.
